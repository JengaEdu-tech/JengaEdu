# JengaEdu

## Building Better Schools, Together.

JengaEdu is a comprehensive school management platform designed to bring school operations together in one system.

### Main modules
- Learners and admissions
- Attendance and downloadable registers
- Fees and learner activity
- School Operations Centre
- ECDE, Lower Primary, Upper Primary and Junior School views
- Meals and contribution planning
- Staff, salaries and expenditure
- Reports and printable documents

### Important
The school name is configurable in the system settings. JengaEdu is the platform name, while each school keeps its own identity.

### Current setup
This version keeps the existing Supabase structure so no immediate database changes are required.
