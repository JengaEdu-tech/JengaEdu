# JengaEdu Beautiful Platform Update

This update adds a polished JengaEdu platform experience while keeping the existing school management system and database structure.

## Brand
**JengaEdu**
*Building Better Schools, Together.*

The platform name remains JengaEdu, while the school workspace name is read from the existing School Settings.

## Included
- Beautiful JengaEdu welcome banner
- Modern responsive cards
- Clear module highlights
- Existing School Operations Centre retained
- ECDE, Lower Primary, Upper Primary and Junior School views retained
- Weekly and termly register downloads retained

No Supabase changes are required for this visual upgrade.
